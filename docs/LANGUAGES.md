Порядок меню:

3. Внизу — языки народов России: татарский (два алфавита), башкирский, якутский.

Порядок популярной группы — редакторский ориентир по общей распространённости, а не измеренный рейтинг пользователей LinkGuard. Аналитика использования языков не собирается. Русский вынесен наверх как широко используемый язык. Группы служат навигации, а не взаимоисключающей лингвистической классификацией.

## Границы покрытия и качество

Это **не все языки народов России и не все тюркские языки**. Пока отсутствуют, например, чувашский, тувинский, алтайский, хакасский, бурятский, калмыцкий, чеченский, аварский, осетинский, удмуртский, коми и марийские языки. Их нет в меню под видом готовых переводов. Буквально полный перечень требует отдельного согласования языков и вариантов письменности.

Новые словари — редакторские черновики, не проверенные носителями. Полнота строк и успешные тесты подтверждают работу локализации, но не языковую точность. Особенно важна вычитка якутского, башкирского и татарской латиницы. В татарской латинице используются ä, ö, ü, ç, ş, ñ, ğ, ı, q, w; это отдельный словарь, не автоматическая побуквенная замена кириллицы.

## Реализация

- Первые пять переводов: `locales/catalog.ts`; новые языки — отдельные `locales/<код>.ts`.
- `lib/i18n.ts` хранит реестр, группировку, выбор языка и подстановку параметров.
- `tt-Latn-RU` выбирает `tt-Latn`; `tt-Cyrl-RU` выбирает `tt`. Ранее сохранённый `tt` продолжает означать кириллицу.
- В интерфейсе используются BCP 47 коды с дефисами. В `_locales` имя каталога для варианта — `tt_Latn`, согласно [документации Mozilla](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Internationalization).
- Для терминологии якутского просмотрен [словарь интерфейса MediaWiki](https://raw.githubusercontent.com/wikimedia/mediawiki/master/languages/i18n/sah.json); это справочный материал, не подтверждение качества всех переводов LinkGuard.
- Арабский интерфейс использует направление RTL; URL, имя LinkGuard и HTTP-коды сохраняют LTR. Китайский перевод — только упрощённая письменность; традиционная автоматически не подменяется упрощённой.
- Неизвестные диагностические сообщения самого браузера остаются в исходном виде. URL, HTTP-коды и методы не переводятся.

## Проверка и добавление языка

Добавить полный словарь с теми же ключами и параметрами, зарегистрировать язык в `lib/i18n.ts`, расширить ожидаемый перечень в `tests/i18n.test.ts`. Затем выполнить `npm run check`, `npm test`, `npm run test:popup`. Новый словарь должен пройти вычитку носителем; этот этап не заменяется тестами.
