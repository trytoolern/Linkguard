# LinkGuard

Минималистичное расширение для поиска нерабочих ссылок на открытой странице. Поддерживает Firefox Desktop 140+; исходники написаны на WXT, Svelte 5 и TypeScript.

## Возможности

- Быстрая проверка HTTP-ответов и глубокая проверка содержимого.
- Очереди с ограниченной параллельностью, отмена и понятные причины неопределённого результата.
- Фильтры, поиск, экспорт CSV и копирование видимых результатов.
- Подсветка подтверждённо неработающих ссылок на исходной странице.
- Интерфейс на 23 языках, включая русский, татарский (кириллица и латиница), башкирский, якутский, казахский и кыргызский.
- Предварительная Chromium-сборка для ручного тестирования в Chromium, Brave и Edge.

## Разработка

Требуется Node.js 22.18+ (для CI используется Node 24).

```sh
npm ci
npm run check
npm test
npm run build
```

Для временной установки в Firefox откройте `about:debugging#/runtime/this-firefox`, выберите **Load Temporary Add-on** и укажите `.output/firefox-mv3/manifest.json`. Временное дополнение удаляется после перезапуска браузера.

`npm run build:chrome` создаёт папку `.output/chrome-mv3`, которую можно загрузить через режим разработчика Chromium-совместимого браузера.

## Что проверяется

Расширение собирает HTTP/HTTPS-адреса из `a[href]` и `area[href]`, нормализует URL и проверяет каждый уникальный адрес один раз. Быстрый режим использует HEAD с ограниченным переходом на GET. Глубокий режим анализирует ограниченный объём HTML, JSON и обычного текста, а подозрительные страницы может дополнительно открыть в изолированной вкладке браузера.

Проверка не доказывает, что бизнес-логика целевой страницы работает: HTTP 200, текст и DOM — лишь наблюдаемые сигналы. Ошибки сети, CAPTCHA, лимиты и запреты доступа остаются отдельным неопределённым состоянием, а не выдаются за рабочую ссылку.

## Приватность

У расширения нет аккаунтов, аналитики и собственного сервера. Адреса из проверяемой страницы отправляются только непосредственно соответствующим сайтам, чтобы проверить их доступность. Результаты хранятся только в сеансе браузера и удаляются после его перезапуска.
